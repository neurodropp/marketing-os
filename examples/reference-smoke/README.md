# Synthetic reference outputs

These files were produced by scripts/run_synthetic_smoke.py and inspected through the local process completion utility. They are authored examples, not independent model evaluations. All data and brands are synthetic. No real accounts were contacted or changed.

- Economics: reproducible contribution calculation, ready within the synthetic data scope.
- Research: instrument and sampling plan, draft because participants/data are absent.
- Paid social: preparation specification, draft because account access, authorization, assets and tracking evidence are missing.
- Experiment: protocol draft, not sized or executed because baseline and traffic are missing.

Run the script with a new --out destination to reproduce the files and state transitions. Existing destinations are not overwritten.
