## Procedure

1. **F3.03.a** — Select personality traits and explain their behavioral implications in writing.
2. **F3.03.b** — Define tone shifts for sales, support, education and sensitive situations.
3. **F3.03.c** — Build preferred vocabulary and discouraged phrases with reasons.
4. **F3.03.d** — Create core identity messages grounded in approved promises.
5. **F3.03.e** — Rewrite representative before-and-after examples and create an editing checklist.

## Output contract

Verbal identity guide: traits, tone matrix, vocabulary, message examples, do/don't pairs and review checklist.

Save the deliverable under `brand/<run-id>/` in the active workspace. Choose Markdown for narrative work, CSV/XLSX for tabular calculations, and native media files where the task requires them.
