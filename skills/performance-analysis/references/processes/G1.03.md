# G1.03 — Funnel and journey analytics

Version: 0.3.0 · Owner: `performance-analysis-agent` · Skill: `performance-analysis`

## When to use

Use when the requested work concerns funnel and journey analytics and needs the following output: Funnel analysis: cohort, entrants, conversions, rate, time window, lag, drop-off, path, limitation.

Read [the process execution contract](../processes.md#execution-contract) before starting. Use only the active brand workspace.

## Inputs and readiness

| ID | Required input to assess |
| --- | --- |
| i1 | Stage definitions |
| i2 | event timestamps |
| i3 | cohort and segment rules |

Bind each input to local evidence or a dated source. Missing data may support a clearly labeled draft or collection plan; it cannot support a verified result. Mark an irrelevant input not applicable with a specific reason.

## Procedure

1. **G1.03.a** — Calculate stage conversion using eligible entrants and explicit windows.
2. **G1.03.b** — Identify drop-off while accounting for incomplete observation periods.
3. **G1.03.c** — Measure time to convert with censoring and timezone handling.
4. **G1.03.d** — Compare observed paths and repeated visits without assuming one linear route.
5. **G1.03.e** — Segment cohorts to test whether aggregate results hide meaningful differences.

## Output contract

Funnel analysis: cohort, entrants, conversions, rate, time window, lag, drop-off, path, limitation.

Save the deliverable under `reports/<run-id>/` in the active workspace. Choose Markdown for narrative work, CSV/XLSX for tabular calculations, and native media files where the task requires them. Include source references, assumptions, decision status and next owner. Never overwrite an accepted version.
